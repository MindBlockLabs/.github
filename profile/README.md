## What is MindBlock?

MindBlock is a next-gen puzzle adventure blending AI-generated challenges with skill-based progression. Players solve logic-based tasks across categories like coding, puzzles, and blockchain - earning XP, sharpening problem-solving skills, and competing socially with friends.

Whether you're a beginner or a pro, MindBlock adapts to you, making every challenge rewarding.

## ✨ Features

- 🧠 Quick IQ-level survey to personalize your journey
- 🧩 Puzzles that evolve with your intelligence level
- 💻 Categories: coding, logic, blockchain, and more
- 🏆 Leaderboards, with real-time puzzle battles coming soon

## 🏗️ Project Structure

MindBlock is a monorepo built across three main components:

| Layer | Stack | Hosting |
|---|---|---|
| **Backend** | NestJS: API & game logic | [Render](https://mindblock-webaapp.onrender.com) |
| **Frontend** | Next.js: user interface | Vercel (coming soon) |
| **Smart Contracts** | Soroban (Rust) | Stellar testnet |
